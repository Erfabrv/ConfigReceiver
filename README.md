# Config Receiver (Android TV)

برنامه‌ای برای اندروید باکس که با آن می‌توانید از گوشی (فقط با مرورگر) کانفیگ‌های v2ray/vless/vmess را به باکس بفرستید.

## ساخت APK
- **با Android Studio:** پوشه را Open کنید، صبر کنید Sync شود، سپس Build > Build APK(s).
- **بدون نصب چیزی (GitHub):** پوشه را در یک ریپوی GitHub آپلود کنید. در تب Actions، بیلد خودکار اجرا می‌شود و فایل APK در بخش Artifacts قابل دانلود است.

## استفاده
1. APK و v2rayNG را روی باکس نصب کنید.
2. برنامه‌ی Config Receiver را روی باکس باز کنید.
3. QR روی تلویزیون را با گوشی اسکن کنید (گوشی و باکس روی یک وای‌فای).
4. کانفیگ را پیست کنید و «ارسال به تلویزیون» را بزنید.
5. روی باکس، کانفیگ را انتخاب و «کپی و باز کردن v2rayNG» را بزنید، سپس در v2rayNG گزینه‌ی Import from clipboard.
